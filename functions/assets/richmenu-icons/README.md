**建立日期**：2026-09-10
**狀態**：⚠️ 佔位圖（placeholder），不是最終版本

## 說明

這批圖是用 Python/PIL 產生的簡化版扁平圖示（圓角漸層徽章 + 白色線稿圖形），
**不是**用 AI 圖片生成模型跑出來的「glossy 3D icon」成品。目前 session 沒有接
AI 圖片生成工具，所以先用程式畫出功能正確、檔名正確、透明背景的佔位版本，
讓 Rich Menu 的程式邏輯可以先開發、先測試，不用卡在等圖。

## 換成正式版的做法

1. 把原本你寫的六段 prompt（統一風格 + 各自主體描述）貼到 AI 圖片生成工具
   （例如 ChatGPT/DALL·E、Midjourney、Gemini 的圖片生成）。
2. 產出後另存成同樣的檔名，直接覆蓋這個資料夾裡對應的檔案即可，程式碼裡的
   路徑不用改。
3. 建議確認尺寸與 LINE Rich Menu 規格相符（LINE 官方建議 2500×1686 或
   2500×843，實際切版時依你的選單版型調整；這批佔位圖是 512×512 純圖示，
   套版時可能需要再排版）。
